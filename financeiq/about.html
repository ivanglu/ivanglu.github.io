About the project

About FinanceIQ

FinanceIQ is a financial research tool built by Ivan Glushchenko, a high-school senior who plans to study finance and data analytics. It turns the annual reports public companies file with the SEC into comparisons, scores and valuations that show their working.

How the data is collected and processed

US public companies must file an audited annual report, the Form 10-K, with the Securities and Exchange Commission. Each number in the financial statements carries a machine-readable tag, and the SEC publishes those tagged numbers through its free EDGAR data service.

  1. Retrieval. A Python script asks the SEC for each company's data, identifies itself as the SEC requires, waits between requests and keeps a local copy so it does not download the same file twice in a day.
  2. Normalization. Companies use different tags for the same idea (there are five common tags for "revenue"). The script tries them in a fixed order, keeps the figure from the original 10-K for each year, rebuilds total debt from its parts, and adjusts per-share figures for stock splits it detects in the filings.
  3. Checks. It tests that assets equal liabilities plus equity, that reported EPS agrees with net income divided by shares, and that no fiscal year is missing. Anything unusual is listed on the Methodology page.
  4. Calculation. The website loads one data file and calculates every ratio in the browser, in a single file of formulas with no page code in it, which is what the automated tests check.

Every formula and scoring rule is on the Methodology page.

How artificial intelligence was used

FinanceIQ was built with Claude Code, an AI coding assistant made by Anthropic. Working from a written specification, the assistant wrote most of the program code, the data pipeline, the automated tests and the technical documentation.

  • AI does no arithmetic on this site. Every number, score and valuation comes from fixed formulas that give the same result every time and can be checked against the filings.
  • AI-written text is labelled. The "Strengths and risks" summaries on the Comparison page are marked as AI-generated, dated and linked to the source filings.
  • Ivan's writing is his own. The research case studies and the personal sections of this page are written by Ivan and are marked "Written by Ivan".

Limitations

  • It looks backwards. Everything is based on annual reports, which can be many months old and say nothing certain about the future.
  • 38 companies. Large US companies in four peer groups plus six others. No banks, insurers or property trusts.
  • Annual data only. No quarterly figures and no live share prices.
  • Simplified definitions. Debt excludes leases. Free cash flow is not adjusted for stock-based pay or acquisitions. ROIC uses book debt plus book equity.
  • The score uses one scale for all industries, which favours high-margin businesses. The benchmarks page corrects for this only within four industries.
  • The DCF is a teaching model. One growth rate, illustrative discount rates, and an answer that moves a great deal when the assumptions change.
  • Tags can be wrong. The data depends on how each company tagged its own filing. The automatic checks catch some problems, not all.

FinanceIQ is an educational project. Nothing on it is investment advice or a recommendation to buy or sell any security.
